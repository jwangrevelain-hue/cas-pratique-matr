# Lecture des chiffres clés

- Base active : **702 abonnés** fin 2026-06, pour un **MRR de 12,353 €**. La base a crû régulièrement depuis 2024-01 puis s'est stabilisée : les nouvelles souscriptions se sont taries début 2026 tandis que les résiliations sont toutes concentrées sur 2026-04–2026-06 (98 départs, soit ~12.2% de la base sur le trimestre).
- **Premium** porte 35% du MRR avec seulement 109 actifs : la valeur est concentrée sur le haut de gamme, alors que Basic domine en volume.
- Le churn est du même ordre sur tous les canaux d'acquisition (12%–16%) : pas de canal 'toxique' évident, la rétention se joue ailleurs (usage).
- Revenu cumulé reconnu depuis l'origine : **220,955 €**.
